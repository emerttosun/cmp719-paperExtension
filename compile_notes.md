# Progress report compile notes

Use the required Overleaf template:
https://www.overleaf.com/latex/templates/template-for-iclr-2025-conference-submission/gqzkdyycxtvt

Steps:

1. Open the Overleaf template as a new project.
2. Replace the template's main `.tex` content with `main.tex`.
3. Upload `references.bib` to the same Overleaf project.
4. Keep the template files `iclr2025_conference.sty`, `iclr2025_conference.bst`, and `math_commands.tex` in the project.
5. Compile with pdfLaTeX.

Note: The local machine currently does not expose `pdflatex` or `latexmk` on PATH, so the PDF was not compiled locally.
